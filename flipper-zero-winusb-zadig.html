TONIEBOX 2 · FLIPPER ZERO · WINDOWS

WinUSB für die Bridge.

Die WebUSB-Bridge aus der vorigen Anleitung läuft auf dem Flipper. Unter Windows ordnest du ihrem USB-Gerät einmalig WinUSB zu, damit der Browser es öffnen kann.

Treiber einrichten ↘Windows · VID:PID 0403:6014

Bevor du Zadig öffnest

Ein Windows-PC · ein USB-Gerät
1

Bridge läuft

Auf dem Flipper ist in Core Flasher die Option Start USB bridge aktiv. Der Flipper ist per USB mit dem Windows-PC verbunden.

2

Nur unter Windows

Dieser Treiberschritt betrifft Windows. Für serielle Pico- oder ESP-Adapter gilt er nicht.

!

Geräte-ID prüfen

Wähle ausschließlich das USB-Gerät mit VID:PID 0403:6014. Ein falscher Treiberwechsel kann andere USB-Geräte unbrauchbar machen.

Windows · Ersteinrichtung

Das richtige Gerät. Der richtige Treiber.

Ist bei 0403:6014 bereits WinUSB eingetragen, überspringe die Installation und fahre beim Abschluss fort.

01

Zadig von der Projektseite öffnen

Lade Zadig von der offiziellen Projektseite und starte die Datei. Bestätige die Windows-Abfrage für Administratorrechte.

Zadig wird nicht installiert; das Programm startet direkt. Die verlinkte Downloadseite benötigt Internet.

↗
Quellezadig.akeo.ie

Offizieller Download · keine Treiberdatei in dieser Anleitung

02

0403:6014 auswählen

Öffne in Zadig Options → List All Devices. Wähle im oberen Gerätefeld den Eintrag mit VID:PID 0403:6014 und kontrolliere die angezeigte USB ID.

Fehlt die ID, prüfe zuerst USB-Verbindung und laufende Bridge. Wähle keinen ähnlich benannten Eintrag auf Verdacht.

● ● ●Zadig
Options → List All Devices
USB ID0403:6014⌄

Geräte-ID vor dem Treiberwechsel prüfen

03

WinUSB zuordnen

Stelle auf der Zielseite WinUSB ein. Zeigt Zadig bereits WinUSB als aktuellen Treiber, ändere nichts. Andernfalls klicke auf Install Driver oder Replace Driver und warte auf die Erfolgsmeldung.

Der Wechsel betrifft die Windows-Treiberzuordnung des gewählten USB-Geräts. Programme, die dessen bisherigen Treiber brauchen, können danach eine erneute Umstellung erfordern.

→
ZieltreiberWinUSB
Abschluss

Neu verbinden. Erkennen.

Nach dem Treiberwechsel muss Windows das Gerät neu erkennen.

04

Flipper erneut verbinden

Trenne das USB-Kabel kurz und verbinde es erneut. Wenn die Bridge nicht mehr läuft, wähle auf dem Flipper Start USB bridge erneut. Prüfe, dass für 0403:6014 jetzt WinUSB angezeigt wird.

Anschließend kannst du im WebUSB-Client des Basis-Plugins die Verbindung zum Flipper wählen. Dieser Schritt installiert keinen Browser-Treiber und liest den Flash noch nicht aus.

✓
WinUSB für 0403:6014 bereit.
